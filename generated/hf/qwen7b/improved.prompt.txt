Write a complete C++17 program for recursive Strassen matrix multiplication.

Command-line and file interface:
- The program is run as: ./matrix input.txt output.txt
- Read the input filename from argv[1] and the output filename from argv[2].
  Open them with std::ifstream and std::ofstream. Do not hard-code any filename,
  do not read from std::cin, and do not print prompts or messages to the console.
- Input TXT format: the first line contains the integer n. The next n lines are
  the rows of A, then the next n lines are the rows of B. Each row has n
  space-separated integers.
- Output TXT format: write exactly n lines to the output file, one line per row
  of C = A * B, with the n integers of the row separated by single spaces and
  each line ending with a newline. Write nothing else to the output file: no n,
  no labels, no brackets, no blank lines, and no explanations.

Algorithm requirements:
- Store matrices as std::vector<std::vector<long long>> and use long long for
  all matrix arithmetic.
- Implement a recursive function strassen(A, B) that returns A * B.
- Base case: when n == 1, return the 1x1 matrix containing A[0][0] * B[0][0].
- Otherwise split A, B into four n/2 x n/2 blocks A11, A12, A21, A22 and
  B11, B12, B21, B22, and compute exactly seven recursive products:
  M1 = strassen(A11 + A22, B11 + B22)
  M2 = strassen(A21 + A22, B11)
  M3 = strassen(A11, B12 - B22)
  M4 = strassen(A22, B21 - B11)
  M5 = strassen(A11 + A12, B22)
  M6 = strassen(A21 - A11, B11 + B12)
  M7 = strassen(A12 - A22, B21 + B22)
  Then combine them:
  C11 = M1 + M4 - M5 + M7
  C12 = M3 + M5
  C21 = M2 + M4
  C22 = M1 - M2 + M3 + M6
  and copy C11, C12, C21, C22 into the top-left, top-right, bottom-left and
  bottom-right blocks of C.
- Do not fall back to ordinary triple-loop multiplication at any size above 1.
- Assume valid inputs: n is 1, 2, 4, or 8 and every entry is in [-9, 9].
  No padding, input validation, or extra boundary handling is needed.
  Keep the implementation simple.

Example. If input.txt contains:
2
1 2
3 4
5 6
7 8
then after ./matrix input.txt output.txt, output.txt must contain exactly:
19 22
43 50

Return only complete C++17 source code, including main() and required includes.

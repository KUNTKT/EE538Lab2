Design two test cases for a C++ Strassen matrix multiplication program.
Use n = 4 for the first case and n = 8 for the second, with entries in [-9, 9].

Case 1 (n = 4) goal: detect swapped operands (computing B * A instead of A * B)
and sign errors in the Strassen differences such as B12 - B22 or A21 - A11.
Use a non-symmetric A and B, where A * B differs from B * A, and include both
negative and positive entries, so that a wrong sign or wrong operand order
changes the result.

Case 2 (n = 8) goal: detect wrong block placement when combining C11, C12, C21,
C22, and errors that only appear after two levels of recursion. Make A a
block-structured matrix whose four 4x4 blocks are clearly different (for
example, one block with small positive values, one block of zeros, one block
with negative values, one block with an identity-like pattern), and make B a
simple matrix such as a permutation or a diagonal matrix with different
diagonal values, so that each block of C is easy to recognize and a
misplaced or transposed block is visible.

For each case, provide a name, a short explanation, an input TXT block,
and a separate claimed output TXT block. Calculate C = A * B.
Input: n on the first line, then n rows of A, then n rows of B.
Output: n rows of C only, without a dimension line.
Do not put labels or brackets inside either data block.
Use small, structured matrices so that a person can check part of the result.
